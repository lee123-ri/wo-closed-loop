李沛东 | 2026-08-06 | 参考：贾总 EAM 原型 v3 + 08-04 听记决议

一、核心定位

软工单面板是一个独立的监控展示层，不替代钉钉审批流，而是作为"状态聚合 + 发起入口"。

架构关系
年度运营计划Agent → 监视Agent → 软工单面板
发起入口 · 状态聚合

钉钉 OA 审批流
派发 · 审批 · 闭环 ⇄ 软工单面板
状态回读 · 结果展示
职责软工单面板钉钉 OA 审批
工单创建✅ 表单填写 → 触发审批—
派发责任人—✅ 审批节点指派
审批流程—✅ 多级审批
状态监控✅ 汇总展示所有工单逐个查看
执行佐证✅ 展示附件✅ 审批中上传
闭环归档✅ 历史记录 + 统计审批单存档
升级催办✅ 面板红色标记✅ 工作通知提醒

执行中蓝色，进度+截止倒计时—责任人
待验收橙色，等审批人确认二次审批（闭环确认）审批人
已闭环绿色，归档审批完成，入审计库系统自动
已逾期红色，超期天数升级催办系统自动

四、面板页面结构

页面作用关键元素
工作台 Dashboard • 四色统计卡：待处理 / 执行中 / 待验收 / 已逾期
• 来源分布环图（年度计划/监视告警/判定会/手动）
• 待办工单列表（按紧急度排序）
• 逾期预警区（红色高亮）

• 批量操作：导出
工单详情 单工单全貌 • 基本信息区：全部字段
• 审批进度条：从OA同步的审批节点状态
• 时间线：创建→派发→执行→佐证→闭环
• 附件/佐证预览
新建工单 发起入口 • 表单（项目、类型、标题、原因、要求、责任人、审批人、截止日期）
• 提交 → 触发钉钉OA审批 → 自动创建OA审批单
• 返回工单列表
闭环记录 归档查询 • 已闭环工单列表
• 按项目/时间/责任人筛选
• 闭环率统计

五、数据存储方案

🏆 推荐：AI 表格

  • 钉钉原生，零运维
  • 看板+表格双视图
  • API 读写，Agent 可操作
  • 支持附件、人员字段
  • 权限可控
  • 开发量：直接用 dws sheet
✅ 推荐

备选：本地 JSON

  • 纯前端，零依赖
  • 无需权限
  • 数据在 HTML 内
  • 多人无法共享
  • Agent 无法写入
  • 仅适合 demo
⚠️ 仅Demo

备选：知识库

  • 结构化存储
  • 版本历史
  • 权限管理
  • 读取需 API
  • 无看板视图
  • 开发量中等
可用

💡 建议分两步

今天下午汇报用：本地 JSON 数据 + HTML 面板（纯前端，即开即用，展示完整交互）
下周实际用：切换到 AI 表格后端，Agent 可读写，多人可协作

六、面板与钉钉审批的交互点

时机面板动作钉钉 OA 动作技术实现
创建工单 用户/AI 填表 → 点击「派发」 自动发起 OA 审批单 dws oa 创建审批实例
审批进行中 显示审批进度条 + 当前节点 审批人在钉钉内审批 定时拉取审批状态 / webhook 回调
审批通过 状态自动变为「已派发」 通知责任人 回调更新 AI 表格 / 面板刷新
执行完成 责任人上传佐证 → 提交验收 发起二次审批（闭环确认） 面板触发二次审批
闭环确认 状态变为「已闭环」，归档 审批人确认通过 回调更新状态
超期 红色标记 + 逾期天数 工作通知催办 面板定时检查截止日期

软工单面板差异化

OA 联动🆕 审批进度条 + OA单号可点击

入场资料❌ 不需要（软工单不涉及）
风险等级❌ 改为紧急/普通/低优先级
