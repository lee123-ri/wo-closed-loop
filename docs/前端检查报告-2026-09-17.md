# 工单平台前端检查与修复报告

日期：2026-09-17
范围：`frontend/src`、工单列表筛选 API，以及本地隔离测试库联调。

## 结论

前端构建、12 项浏览器回归、17 项相关后端测试通过；12 个主要页面在隔离测试库上可打开，没有浏览器运行时异常。已修复会误导用户的筛选、必填、错误态和宽表溢出问题，并统一高频表单与导航组件。代码仍在当前工作区，未部署生产。

## 已修复的问题

| 领域 | 原问题 | 处理结果 |
| --- | --- | --- |
| 我的工单 | “待回填”卡点击到“执行中”；待处理、执行中统计口径与单一状态筛选不一致 | 新增后端 `bucket` 筛选；待处理含 pending/approving，执行中含 dispatched/executing，待回填按未完成回填筛选；“全部”包含归档以对齐总数 |
| 新建工单 | 红星字段可空提交，打开时还会自动选择第一项目和类型 | 明确校验项目、类型、来源、优先级、标题、行动、责任人、审批人、截止日期；项目和类型由用户选择，切换项目重置责任人并带入合法区域 |
| 工单详情 | 404 无限“加载中”；辅助接口失败使整页打不开；OA 驱动单仍显示无效流转按钮；措施草稿保存失败仍继续流转 | 增加统一错误态及返回入口；辅助接口降级；隐藏 OA 单本地流转按钮；保存失败停止确认并提示 |
| 列表操作 | 派发抽屉能先写空人员再派发；快速切换措施草稿可能回显错行；闭环缺确认 | 提交前校验人员、丢弃过期请求、闭环前确认 |
| 视觉与可用性 | 宽表把页面撑到 1724px；导航混用 emoji；新建、项目、数据池表单样式不一 | 宽表改为卡片内滚动；统一 TDesign 图标与高频表单；统计卡支持键盘和聚焦；按钮、圆角、焦点反馈使用统一变量 |
| 加载反馈 | 看板、项目、用户、日志、配置失败时显示空白或“暂无数据” | 统一错误组件并提供重试；配置保存加入防重和失败提示 |
| 导出与上传 | CSV 引号、逗号、换行可串列，表格公式可能被执行；“导出 CSV”范围不明；上传手写 multipart 请求头 | 共用 CSV 转义与公式保护；按钮明确为“当前页”；交由浏览器生成 multipart 边界 |
| 图表 | 图表实例未释放，窗口缩放不重排，打包包含整个 ECharts | 卸载释放、缩放重排、按图表组件引入；看板资源从约 1045KB 降至约 511KB |
