# 软工单管理平台 — 工作流总结与调整

> 2026-08-12

---

## 当前四阶段工作流

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  来  源   │ →  │  派  单   │ →  │  监  视   │ →  │  闭  环   │
│  SOURCE   │    │ DISPATCH  │    │ MONITOR   │    │  CLOSE    │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 一、来源 — 工单从哪里来

| 入口 | 方式 | 状态 |
|------|------|------|
| 手动创建 | 前端表单 | 保留 |
| 听记解析 | LLM/正则 | 保留后端、隐藏前端 |
| CSV 表格导入 | 上传 CSV | 保留后端、隐藏前端 |
| **数据池 — AI表格同步** | 钉钉 AI 表格 API → 数据池 → 生成 | **主入口** |
| **数据池 — CSV 上传** | Excel → 数据池 → 生成 | 保留后端、隐藏前端 |

**调整：** 前端只暴露 AI 表格同步入口，其他渠道后端保留但界面隐藏。

---

### 二、派单 — 工单怎么到人

**当前：** 每条工单创建 → 发起钉钉 OA 审批 → 审批通过 → 派发到责任人

**问题：** 全年工单一次性批量创建（几百条），逐条 OA 审批不现实。

**调整：** 按工单类型区分派单策略

| 工单类型 | 派单方式 | 说明 |
|---------|---------|------|
| **计划类 (plan)** | 跳过 OA，直接 dispatched | 预分配好的年度计划，责任人已知 |
| **异常类 (anomaly)** | 走 OA 审批 | 非预期事件，需审批确认 |

**新增机制：**

```
计划类工单批量生成
  │
  ├─ status = "dispatched"（跳过 OA）
  ├─ 同步到钉钉待办 (dws todo)
  ├─ 加入工单日历
  └─ deadline 前 N 天提醒
       ├─ 钉钉工作通知
       └─ 群机器人 @责任人
```

---

### 三、监视 — 谁来盯、盯什么

**当前：** 只有管理看板（PMO/PIO 视角）

**调整：** 双视角

| 视角 | 路由 | 受众 | 内容 |
|------|------|------|------|
| **管理看板** | `/` | PMO/PIO/管理层 | 全部工单、逾期、SLA、人员分布 |
| **我的工单** | `/my` | 责任人/厂长 | 我的待办、回填、日历、提醒 |

**我的工单页面：**
- 统计卡片：待处理 / 执行中 / 待回填 / 已逾期
- 工单列表（逾期优先）
- 工单日历（我的 deadline）
- 回填入口（一键跳转填写原因措施）

---

### 四、闭环 — 工单怎么结案

**不变：** 执行 → 提交佐证 → 验收 → 闭环 + 回填原因措施

**新增：** 回填数据写回 AI 表格，形成"识别→分析→执行"完整链路。

---

## 待办调整

基于以上，需要做的改动：

1. **前端入口精简** — 隐藏听记/CSV/手动导入，只留 AI 表格同步
2. **计划类工单跳过 OA** — `pool_type=plan` 生成时直接 dispatched + 待办 + 日历
3. **钉钉待办同步** — 生成工单时同步创建钉钉待办 (`dws todo`)
4. **我的工单页面** — 新增 `/my` 路由，责任人视角
5. **截止提醒** — deadline 前一天/当天/逾期后钉钉通知
