# 工单闭环平台 v0.7.0 部署交接说明

## 交付物与目标

本交接包包含源码包、数据库快照和校验文件。恢复后线上应具有本地清场后的同一份业务数据：3468 位用户、3906 个项目、34 条配置定义、31 条工单（其中 20 条已闭环）。数据库快照含个人与业务数据，仅限本次内网部署使用，不得上传公共网盘或提交代码仓库。

## 部署方需要准备的内容

| 内容 | 用途 | 是否阻塞 |
| --- | --- | --- |
| ACK 集群 kubeconfig / 部署权限 | 创建 Deployment、Service、Ingress，执行迁移和检查 | 是 |
| ACR 命名空间与推送凭据 | 存放后端、前端镜像 | 是 |
| 新建的 RDS PostgreSQL 15 数据库及账号 | 恢复本交接包的业务数据 | 是 |
| Tair/Redis 连接地址 | Celery 任务、缓存、异步通知 | 是 |
| 正式 HTTPS 域名与 ALB 证书 | 钉钉 OAuth 回跳、用户访问和 HTTPS | 是 |
| 钉钉内部应用 AppKey/AppSecret/CorpId/OA 模板 | 登录、OA 发起与状态同步 | 是 |
| 李沛东的钉钉 userId | 锁定“历史工单导入”唯一运维入口 | 是 |
| OSS 配置 | 工单附件存储；未启用附件时可暂缓 | 否 |
| dws 凭据包 | 钉盘/AI 表格自动同步；当前默认关闭自动历史导入 | 否 |

## 部署步骤

1. 解压源码包，按 `docs/云效-ACK正式上线清单.md` 构建并推送两个镜像。镜像标签必须使用不可变 tag，不用 `latest`。
2. 创建空的 RDS 数据库；不要执行 `python -m app.seed`。
3. 从交接包取出 `wo_closed_loop_current_*.dump`，恢复到新库：

   ```bash
   pg_restore --clean --if-exists --no-owner --no-privileges \
     --dbname='postgresql://<user>:<password>@<rds-host>:5432/wo_closed_loop' \
     wo_closed_loop_current_*.dump
   ```

4. 在云效凭据库或 ACK Secret 创建 `wo-secrets`。必须设置：

   ```text
   APP_ENV=production
   AUTO_SEED=false
   NAME_LOGIN_ENABLED=false
   DEV_LOGIN_ENABLED=false
   AUTO_WORKORDER_IMPORT_ENABLED=false
   BULK_IMPORT_OWNER_DINGTALK_ID=<李沛东的钉钉userId>
   DATABASE_URL=...
   REDIS_URL=...
   JWT_SECRET=<随机值>
   DINGTALK_APP_KEY=...
   DINGTALK_APP_SECRET=...
   DINGTALK_CORP_ID=...
   DINGTALK_OA_TEMPLATE_ID=...
   DINGTALK_LOGIN_REDIRECT_URI=https://<正式域名>/login
   FRONTEND_BASE_URL=https://<正式域名>
   CORS_ORIGINS=https://<正式域名>
   ```

5. 将 `docker/k8s.yaml` 内镜像地址替换为实际 ACR 不可变 tag，执行 `kubectl apply -f docker/k8s.yaml`；逐个等待 backend、worker、scheduler、frontend 就绪。
6. 进入后端 Pod 执行 `alembic upgrade head`，它只补齐版本差异，不灌种子数据。
7. 在钉钉开放平台登记正式登录回调地址 `https://<正式域名>/login`；按部署清单配置 OA 回调。

## 验收清单

- `/health` 返回 200，四个 Deployment 均 Ready。
- 数据库计数：用户 3468、项目 3906、配置定义 34、工单 31；允许后续系统运行产生新增记录。
- 登录页仅有钉钉登录，不出现开发登录、钉钉集成或数据池菜单。
- 用李沛东账号登录后，工单列表出现“历史工单导入”；其他账号不可见且请求接口返回 403。
- 一次历史文件导入先预览、勾选、确认，仅产生被勾选的工单。

## 失败处理

- 恢复失败：删除目标空库后重新执行 `pg_restore`，不要在已部分恢复的库上反复叠加恢复。
- 镜像或健康检查失败：回退至上一已验证镜像 tag；不要将 `latest` 视作回滚版本。
- 钉钉登录失败：优先核对回调地址、域名 HTTPS、AppKey/AppSecret 和钉钉后台登记是否完全一致。
