第一部分　指标异常：FLE50 月度曲线

4~5月 FLE50 = 9.70 / 14.03，超阈值5（告警）→ 触发处置流程；6~7月回落至 4.03 / 0.80，回到正常范围。FLE50 为风机故障维修指标（仅含非计划停机的故障损失电量）。

第二部分　原因分析（机位×系统×具体问题 + 共性/偶发定性）

定性判定标准：共性问题＝跨机位同类问题（同一部件/同一机理出现在 ≥2 台机组）或同机位同类问题反复（≥3 次）——指向系统性原因（设计/批次/维护规程缺陷），处置方式为专项整改/普查/培训；偶发问题＝单点一次性事件（处置后未再发）——指向个体失效，处置方式为单次维修+超时复盘。

2.4 定性总结

共性问题是 4~5 月超标的主体：润滑回路（8台/20.9万）、滤芯（4台/8.8万）、变桨PLC（4台/9.9万）、UPS（2台/6次）、制动器（3台）等同类缺陷跨机位集中暴露——指向维护规程与部件批次的系统性短板，而非运气不好。

4.4 复盘结论：指标升降的真实机理

上升（4~5月）＝关键事件集中发生：4月为多台散发换件事件（滤芯/油泵/分配器/液压管路）；5月为 F15 变频超大单事件（67.5%）+ F41/F06 一次性换件 + F14 通讯线反复。
下降（6~7月）＝事件逐个一次性闭环 + 共性缺陷批量整改后无新发：
① 绝大多数关键事件是一次性维修/换件解决（换滤芯/油泵/分配器/滑环/传感器），解决后同类故障再没发生——这是"一次性解决疑难故障"形态；
② 变桨DO控制回路1号线虚接是跨3台机的共性缺陷，6~7月批量整改——这是"针对性技改/维护"形态，但范围是涉及缺陷的机组而非全场；
③ F14 通讯线问题经4次处理（重接→封补→封补）于5-24压住——提示同类故障反复≥3次时，一次性封补不够，应升级为根因排查（与此前"F14问题机组"发现一致）。
未发现"全场统一技改/统一维护"导致回落的证据；叶片类工作（大修/在线监测）在计划性停机通道，与 FLE50 升降无因果（按既定口径）。

4.5 对"定位问题逻辑"的规则启示

① 事件维度（机位×故障）是复盘主线：系统维度聚类（变桨/变频/主控）能发现跨机位共性缺陷（DO回路、Profibus通讯线），但会掩盖"一单超大"（F15占67.5%）与"问题机组"（F14）的结构——正式规则中，Top问题应同时按两个维度输出：事件榜（机位×故障按损失排序）+ 共性榜（跨机位同类缺陷）。
② "不再发生"验证应成为工单闭环标准：每个关键事件的工单，完成标志建议统一为"该机位同类故障 N 周内零发生"。
③ 反复故障升级规则：同机位同类故障 ≥3 次（如F14通讯线），应升级为根因排查工单，而非重复处置。
