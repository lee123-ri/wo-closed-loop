# v0.7.0 交付报告

日期：2026-09-18  
分支：`feature/role-organization-notification`  

## 交付内容

- 新建“用户与组织”中心：权限角色配置、业务岗位、人员授权、岗位映射、待确认候选、项目群同步、机器人通知规则与运行事件。
- 权限角色管理菜单、操作与数据范围；原有 `users.role` 仅为平滑迁移兼容，服务端已支持权限角色参与管理员/审批人和数据范围判定。
- 钉钉部门/项目群同步只产生待确认候选；正式岗位必须人工确认。项目群只按已绑定钉钉 ID 匹配，不按姓名猜测。
- 通知统一为机器人私聊、机器人群聊两种渠道；规则默认关闭，可先试算，带冷却期与运行事件记录。旧通知策略接口返回迁移提示，不再可配置。
- 新增迁移 `n001_add_unified_role_center`，并收紧审计日志为管理员可读。
