# 角色、组织同步、通知与运维方案

## 已确认口径

- 权限角色管理菜单、操作与数据范围；业务角色管理责任、审批、升级对象。
- 钉钉是人员、部门、职位的事实来源；本地映射结果先进入待确认草稿，确认后才生效。
- 业务岗位首批覆盖：场站人员、运检工程师、项目经理、PMO、区域 PMO、区域总经理、区域副总经理、总部人员。
- 项目人员只能由已绑定的钉钉项目群或项目部门导入，禁止按姓名猜测项目归属。
- 通知仅使用机器人私聊与机器人群聊，规则均支持草稿、试算、启停、限频和重试。
- 审计日志记录业务变更；运行事件记录投递、同步和任务失败，并通过追踪号关联完整文件日志。

## 实施顺序

1. 统一权限角色、业务岗位、项目岗位和同步候选模型，保留既有配置兼容读取。
2. 接入钉钉通讯录、部门、群成员的增量拉取，生成差异预览与待确认岗位草稿。
3. 按岗位解析升级路径，先生成升级记录，再接入两种机器人通知规则。
4. 补充运行事件台账、投递记录和集成健康页。

每阶段先覆盖迁移、规则解析、权限范围和失败分支测试；真实钉钉拉取、群同步、私聊或群聊发送均另行联调验收。
